## Requirements
- [ ] Deployed Kubernetes cluster using Kubeadm
- [ ] Deployed Nginx application on Kubernetes through user access
- [ ] Configure K8s RBAC to use Certificate Signing Requests to get access to the
K8s API on the Ngin
- [ ] Commit deployment files to Github and share with Teleport team 24 hours
ahead of the interview
- [ ] Use Cert Manager for Issuing SSL certs for Nginx site
- [ ] The Nginx site must be reachable from your web browser

### Advanced Optional
- [ ] Deploy Nginx Application on kubeadm Kubernetes using GitOps
